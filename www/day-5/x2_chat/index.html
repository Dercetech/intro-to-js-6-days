Extra x2 – Mini-chat

Ouvrez Network avant chaque action. Les messages se rechargent automatiquement toutes les secondes.

Prêt

1. Chargez les messages existants.
2. Envoyez-en un ou deux.
3. Rechargez → le nouveau message doit apparaître.
4. Testez le bouton Effacer.
5. Observez GET vs POST dans Network (method + payload).
6. Repérez le GET automatique toutes les secondes.
